SOHAN ENGINEERING PORTFOLIO - START HERE

1. Open this whole folder in VS Code:
   File > Open Folder > Sohan_Engineering_Portfolio_Starter

2. Double-click index.html to preview the website in your browser.

3. Your main homepage files are:
   index.html
   style.css

4. Individual project pages are inside:
   projects/

5. Temporary project images are inside:
   images/

6. When you have real project photos, replace the SVG placeholders and update
   the image filenames in index.html and each project page.

7. Export your resume as a PDF and put it inside the resume folder with the name:
   Sohan_Bhamare_Resume.pdf

The project cards already have the hover effect:
- image darkens
- image blurs
- image slowly zooms
- "View Project ->" appears
- clicking the card opens the individual project page
